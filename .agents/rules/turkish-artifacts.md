# Türkçe Artifact Kuralı

Tüm artifact markdown dosyalarını (implementation_plan.md, walkthrough.md, task.md, analiz raporları vb.) **Türkçe** yaz.

Bu kural şunları kapsar:
- Başlıklar, açıklamalar, bölüm isimleri
- Tablo ve liste içerikleri
- Alert/uyarı metinleri

Bu kural şunları **kapsamaz**:
- Kod içindeki yorumlar ve değişken/sınıf isimleri (bunlar İngilizce kalabilir)
- Commit mesajları (İngilizce kalabilir)
- Kod blokları içindeki string'ler
